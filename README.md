# VogueStock | ক্লোথিং ব্র্যান্ড ইনভেন্টরি ও ক্যাটালগ

Single-file Bengali clothing-brand inventory & catalog app (VogueStock IMS).

- Pure client-side: data stays in the visitor's browser (IndexedDB / localStorage)
- Features: SKU catalog, size/color, cost/MRP, stock in-out, low-stock alerts, Excel import/export (.xlsx), JSON backup/restore, WebP image compression
- Default login shown on the login screen: 1234 (changeable inside Settings)

Live site is served from this repo via GitHub Pages.
